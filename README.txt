GMS Toolkit v0.4.2 — Vercel Deploy Package

Files:
- index.html   Main app
- vercel.json  Minimal Vercel static-site config

Deploy options:
1. Drag this folder into Vercel if your Vercel interface supports local upload.
2. Or upload these files to a GitHub repository and import that repository into Vercel.

No build command, framework, environment variables, database, or server is required.
The app stores character/tool data in the browser's localStorage for the deployed domain.
